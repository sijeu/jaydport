# Yo Sijeu — Little Portfolio

A responsive, single-page portfolio inspired by the supplied pastel Chiikawa and Cinnamoroll reference.

## Run it

Open `index.html` in a browser. The HTML, CSS, JavaScript, and character art are all included in this folder. Google Fonts are optional; the page falls back to system fonts when offline.

## Projects

The Featured Projects section links to these included project pages:

- `projects/guray-act3/GurayAct3/home.html` — My Personal Website
- `projects/guray-act4/gurayAct4/landing.html` — Sweet Pastries
- `projects/final-act3/GURAY_FinalACT3/index.html` — Student Profile
- `projects/finals-act/Guray_FinalsAct/login.html` — Jaydelyn Login
- `projects/student-registration/StudentReg.html` — Student Registration

Keep the `projects/` folder beside `index.html` so the links work.

## Character assets

The raster illustrations in `assets/` are crops from the reference image supplied for this project. They are reused as image files throughout the page; no character drawings are hardcoded in HTML, CSS, or SVG.

## Personalize

Update the sample name, biography, skills, and project labels in `index.html`. Replace `hello@example.com` with your preferred contact email.
